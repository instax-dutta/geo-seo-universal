# geo-seo-universal

**Universal AI-powered GEO/SEO audit tool for agents.**

GEO-first, SEO-supported. Optimize websites for AI-powered search engines (ChatGPT, Claude, Perplexity, Gemini, Google AI Overviews) while maintaining traditional SEO foundations.

> **Cross-platform:** Works with Claude Code, OpenCode, Codex, KiloCode, and any agent that supports the Model Context Protocol (MCP) or standard Markdown skill files.

## Quick Start

### One-Command Install (macOS/Linux)

```bash
curl -fsSL https://raw.githubusercontent.com/instax-dutta/geo-seo-universal/main/install.sh | bash
```

### Manual Install

```bash
git clone https://github.com/instax-dutta/geo-seo-universal.git
cd geo-seo-universal
./install.sh
```

### For OpenCode / Codex / KiloCode

```bash
npx skills add https://github.com/instax-dutta/geo-seo-universal
```

### For Hermes Agent

```bash
hermes skills install geo-seo-universal
```

## Features

- **AI Visibility Audit** — Check how well AI search engines find and cite your brand
- **Content Optimization** — Rewrite content for GEO (Generative Engine Optimization)
- **Schema & Technical SEO** — Structured data, Core Web Vitals, and crawlability
- **Platform Analysis** — Per-platform optimization for ChatGPT, Claude, Perplexity, Gemini
- **Brand Mentions Tracking** — Monitor unlinked brand mentions across the web
- **Citation Building** — Get listed in AI training data sources
- **LLMs.txt Generation** — Create `llms.txt` files for AI crawlers
- **PDF Reporting** — Export audit results as professional PDFs
